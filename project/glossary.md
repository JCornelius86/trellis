# Glossary

| Term | Meaning |
| --- | --- |
| Trellis | The local hub. A starting point and project view, not a workflow. |
| Project | One GitHub repo plus one Figma file. |
| Flow | One Figma section moving through Wireframes, Explorations, and Current. The main unit in Trellis. |
| Round | One prompt-and-design iteration within a flow. Trellis starts it; follow-ups happen in Copilot and Figma. |
| Context | The brief, assumptions, decisions, and glossary files in `project/`. |
| Scope | An optional Figma frame or section the task applies to. |
| Prepared task | Goal, scope, and context assembled into instructions for Copilot. |
| Hand-off | Sending the prepared task to Copilot as an assigned issue. Doesn't prove a session started. |
| Verified | Read directly from GitHub or Figma, with source and date. |
| AI summary | Interpretation written by a model. Always labelled. |
| Approval gate | A point where work stops until a person agrees. |
| Wireframes | Figma page for lo-fi flows and alternatives. Never labelled hi-fi. |
| Explorations | Figma page for design-system-based hi-fi alternatives. Never built from directly. |
| Current | Figma page of agreed designs eligible for implementation. |
| Working | Existing designer-owned Figma content. Never edited by an agent. |
